## Description

This project contains a Python script (`243464 ATM CODE.py`) that simulates the functionality of an Automated Teller Machine (ATM). The script allows users to perform basic banking operations such as checking balance, withdrawing funds, and depositing funds.

## Usage

To use the ATM simulator, you need to have Python installed on your system.

1.  Download the `243464 ATM CODE.py` file.
2.  Open a terminal or command prompt.
3.  Navigate to the directory where you saved the file.
4.  Run the script using the command: `python "243464 ATM CODE.py"`
5.  Follow the on-screen instructions to interact with the ATM.

## Features

*   **Check Balance:** Allows users to view their current account balance.
*   **Withdraw Funds:** Enables users to withdraw money from their account.
*   **Deposit Funds:** Allows users to deposit money into their account.
*   **User-Friendly Interface:** Provides a simple and intuitive command-line interface.
